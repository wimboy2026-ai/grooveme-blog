## 一、Obsidian Git 自动同步配置

### 1. 安装插件
- 打开 Obsidian → 设置 → 第三方插件
- 关闭安全模式
- 搜索安装 **Obsidian Git**

### 2. 插件配置
```
Automatically commit: ✅ 开启
Commit interval: 5 分钟
Automatically push: ✅ 开启
Pull before commit: ✅ 开启
Commit message: update: {{date}} {{time}}
```

---

## 二、Notion 同步配置（可选）

### 1. 创建 Notion Integration
1. 打开 https://www.notion.com/my-integrations
2. New integration → 命名如 `obsidian-sync`
3. 复制 Internal Integration Secret

### 2. 创建 Notion 数据库
1. 新建页面 → 创建 Database (Table)
2. 字段：Name, tags, date, status
3. 分享给集成

### 3. 安装 Obsidian to Notion 插件
1. 社区插件市场搜索安装
2. 配置：
   - Notion API Token: 粘贴刚才的 Secret
   - Database ID: 32位数据库ID

## 四、Netlify 自动部署配置

### 1. Build Settings
```
Build command: npm run build
Publish directory: .next
```

### 2. 环境变量
```
UPSTASH_REDIS_REST_URL: (你的值)
UPSTASH_REDIS_REST_TOKEN: (你的值)
```

### 3. netlify.toml（已配置）
```toml
[build]
command = "npm run build"
publish = ".next"

[functions]
directory = ".next/server"

[[redirects]]
from = "/*"
to = "/index.html"
status = 200
```
